# Development Roadmap

## Milestone 0 — Baseline
Inspect repo, settle structure, add docs, establish tool versions, lint/test/build commands and initial CI. Exit: frontend/backend skeletons build.

## Milestone 1 — Web platform
React shell, Spring Boot, PostgreSQL, Flyway, auth, profile, error conventions. Exit: register/login/profile works.

## Milestone 2 — Historical learning
Era/content/source schema, timeline, event/person/place pages, editorial workflow. Exit: player sees published sourced content only.

## Milestone 3 — Quiz and progress
Quiz schema, attempts, server scoring, explanations, progress. Exit: quiz result persists.

## Milestone 4 — Phaser foundation
React lifecycle, GameBridge, static 2.5D map, camera, selection, touch basics. Exit: scene loads and cleans up correctly.

## Milestone 5 — Mission/management
Campaign, mission, objective tracking, simple resources, one building/action, server validation and rewards. Exit: end-to-end mission completes and resumes.

## Milestone 6 — MVP content and release
Văn Lang and Âu Lạc content, reviewed questions/sources, achievements, responsive UI, tests, performance and deployment. Exit: MVP acceptance scenarios pass.

## Priority
P0: auth, history, quiz, mission progress, persistence, security.
P1: Phaser map, resource interaction, achievements, admin workflow.
P2: richer animation, advanced scenarios, leaderboard.
Deferred: multiplayer, large RTS, complex AI opponents, monetization.

Every task needs value, scope, dependencies, acceptance criteria, test plan and exclusions. Estimate after repository inspection and technical spikes.
