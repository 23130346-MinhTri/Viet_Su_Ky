# Reusable Prompts for AI Coding Agents

## Repository audit
Read the docs and inspect the actual repository. Report tree, technologies/versions, modules, build/test commands, conflicts and prioritized gaps. Do not modify files.

## Implement a vertical slice
Implement: [feature]. Inspect existing code and docs first. State plan and acceptance criteria. Implement the smallest complete slice, tests and integration. Avoid unrelated scaffolding. Run checks and report exact outcomes.

## Database change
Design [change]. Inspect current migrations. Provide entities, relationships, constraints, indexes, Flyway migration, rollback considerations and tests. Never edit an applied migration.

## Phaser feature
Implement [feature]. React owns lifecycle/UI; Phaser owns rendering/input; backend owns authoritative state. Use GameBridge. Include cleanup, error/loading states and verification.

## Historical content draft
Prepare draft content about [topic]. Do not invent facts or sources. Classify claims, list verification gaps, include only verifiable source metadata, mark DRAFT and do not publish.

## Code review
Review diff for scope, architecture, security, historical integrity, errors, performance and tests. Group findings by severity and cite file/line. Do not rewrite unless asked.

## Release readiness
Assess MVP against SRS, testing and security docs. Produce a requirement-to-evidence matrix with pass/fail/partial/not tested. Code existence alone is not proof.
